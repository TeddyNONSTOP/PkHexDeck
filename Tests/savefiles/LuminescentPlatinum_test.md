# LuminescentPlatinum_test.bin

A synthetic Luminescent Platinum save made for tests; it contains no player's data.

It was generated with PKHeX.Core from a blank `SAV8BSLuminescent` (trainer "DECK", TID 12345 / SID 54321,
English): the first 60 non-egg, Sinnoh-dex Pokémon from `gen8b_brilliantdiamond.bin` (a public RoCs-PC save
already in this folder) were copied in as `PB8LUMI` with the trainer's OT and ID, followed by level 5 Snivy,
Froakie and Rowlet (species past the Sinnoh dex). The first three were then moved into the party. The file is
979,108 bytes with valid checksums.
